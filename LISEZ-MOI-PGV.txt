EMAIL DE DOCUMENTATION
La notification utilise Resend (email transactionnel séparé de Supabase Auth). Depuis la racine du dépôt, après avoir créé et vérifié le domaine expéditeur chez Resend, configurer les secrets sans les écrire dans les fichiers :
  npx --yes supabase secrets set RESEND_API_KEY="VOTRE_CLE_RESEND" MAIL_FROM="Sigma <notifications@votre-domaine-verifie.ma>" APP_PUBLIC_URL="https://sigma.acx.ma" --project-ref VOTRE_PROJECT_REF
Puis déployer :
  npx --yes supabase functions deploy pgv-send-agent-document --no-verify-jwt --project-ref VOTRE_PROJECT_REF
La fonction vérifie côté serveur le rôle, profiles.activity='pgv', la visibilité du document et le destinataire. Le logo est chargé depuis l'asset public Sigma.
